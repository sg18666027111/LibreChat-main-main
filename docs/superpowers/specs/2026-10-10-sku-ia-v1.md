# SKU 图制作 · 信息架构说明（v1）

**日期：** 2026-10-10  
**状态：** 已确认  
**前提：** 沿用现有 Sharp 合成、任务与稳定文件 ID；不重写核心合成。

## 1. 目标与原则

- 「SKU 图制作」是**独立功能**：运营在同一功能区内完成「出源图 → 制 SKU」。
- 侧栏**同时保留**「AI 生图」与「SKU 图制作」，二者并存、互不替代。
- 侧栏图标必须**视觉可区分**（当前共用 `ImageIcon` 需改掉）。
- 合成阶段不调用 AI / 图像供应商。

## 2. 侧栏信息架构

| 入口       | 路由                | 说明                                                                               |
| ---------- | ------------------- | ---------------------------------------------------------------------------------- |
| AI 生图    | `/image-generation` | 文生图、单图改图、批量等原有能力，保持不变                                         |
| SKU 图制作 | `/sku-generation`   | 独立功能区；图标换独立符号（如 LayoutTemplate / Package / Tags），不与 AI 生图相同 |

- 两入口都在侧栏展示；不把侧栏收成只剩 SKU。
- 按 `pathname` 正确高亮当前入口。

## 3. SKU 功能区内两步

进入「SKU 图制作」后：

**步骤 1 · 出源图**

- 区内嵌 / 复用「单图改图」能力，做出可用源图；或
- 直接上传一张源图。

**步骤 2 · 制 SKU**

- 配置左/右图标与文字列表；
- 实时预览首条版式；
- 批量生成、预览、下载、失败重试、取消；
- 「再次制作」「继续单图改图」仍走稳定文件 ID。

状态节奏：

- 无源图 → 停留步骤 1；
- 有源图 → 进入步骤 2；可「更换源图」回到步骤 1。

## 4. 与「AI 生图」的关系

- **并存**：AI 生图继续服务通用生图/改图场景。
- **SKU 自包含**：主路径不依赖先去 AI 生图再找按钮；单图改图在 SKU 区内即可完成。
- **可选快捷**：AI 生图里 `image-to-image` 结果卡可保留「制作 SKU 图」，带 `sourceFileId` 深链进入 SKU 步骤 2；非主路径。

## 5. 路由与数据

- 主路由：`/sku-generation`
- 深链示例：`/sku-generation?sourceFileId=<id>&sourceType=image-edit-result|direct-upload|sku-result`
- 源图 / 图标 / 结果均落稳定文件记录；任务沿用「子任务文档 + 汇总推导」即可。
- API / Sharp 合成沿用 PR 已实现部分。

## 6. 首版范围

**做**

- 侧栏双入口 + 图标区分；
- SKU 区内步骤 1（单图改图或上传）+ 步骤 2（批量合成）；
- 来源标识、鉴权预览下载、文字换行与行数限制。

**不做**

- 多模板、素材库、CSV、自由拖拽、复杂图层编辑；
- 因数据结构与设计文档不完全一致而做库表重构（现有模型够用则保留）；
- 顺手重构其他 AI 生图模块。

## 8. 侧栏内容面板（防功能串用）

- 「SKU 图制作」「AI 生图」及管理类全页工具均为 **routeOnly**：点击只跳转全页，不展开会话列表面板。
- 展开侧栏时，若当前 active 为 routeOnly 且无 `Component`，**不得回退**显示「对话列表 / Conversations」。
- 进入 `/sku-generation`（及同类全页路由）时收起内容轨，仅保留图标轨；SKU 图标保持与 AI 生图可区分（`LayoutTemplate`）。
